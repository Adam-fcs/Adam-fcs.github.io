# Chuanshuai (Adam) Fu Academic Website

Static academic personal website based on the 2026 CV of Chuanshuai (Adam) Fu.

## Pages

- `index.html` - homepage with introduction, profile photo, research overview, and selected awards
- `research.html` - research themes, education, and research appointments
- `publications.html` - publications and scholarly profiles
- `talks.html` - selected talks and posters
- `gallery.html` - personal photo gallery

## Assets

- `assets/profile-photo.jpg` - homepage and gallery photo
- `assets/arctic-ocean-banner.png` - Arctic Ocean visual banner
- `assets/cv-chuanshuai-adam-fu-2026.pdf` - archived CV copy, not linked from the homepage

## Publish on GitHub Pages

Create a repository named `username.github.io`, copy these files into the
repository root, commit, and push. GitHub Pages will serve the site at
`https://username.github.io/`.
